## INTRODUCTION
MVC-ARENA is a fun, educational card game about building a secure software system.
You race your opponent to build a complete **MVC (Model–View–Controller)** program
while defending it from security threats.

You build your program in three lanes: **Model**, **View**, and **Controller**.
You collect the right components in each lane, make them stronger, and protect them
from attacks and disasters. The first player to collect the required components
**and** reach the score limit wins.

**The game includes:**

+ **Component cards** (each worth 1 point)
  - Model: Caching, Data Validation, Database, File Storage Adapter, ORM, Secrets Manager
  - View: Web View, Mobile View, CLI View, Input Validation
  - Controller: Authentication, Authorization, Routing, Middleware, Rate Limiting, CSRF Protection
  
+ **Inheritance card**
  - Starts a stack in a lane
  
+ **Defensive cards** (point multipliers)
  - Interface, Git, Error Handling, Logger
  
+ **Polymorphism card**
  - A wildcard that becomes any component you choose
  
+ **Attack cards**
  - DoS, SQL Injection, XSS, CSRF, Ransomware, Malware, Unauthorized Access
  
+ **Destructive events**
  - Bug, Disaster
